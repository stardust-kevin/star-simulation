帮助与说明

一、顶部与进度条
SSE dot 绿点表示与 Node 后端已连接，红点表示断开。
? 打开本帮助弹窗。
i 关于本软件与更新日志。
中 / EN 中英双语切换。
➖ 折叠控制面板（折叠后出现右上悬浮球，可拖拽回显）。
Progress 进度条分三层：白色块表示 G-code 执行密度，蓝色为执行进度，黑色竖线是层分割线。
二、运行控制
Run / Pause 开始或暂停播放。运行时会同时把整份程序同步到 Node 后端，供 Hermes 通过 TCP 查询 M114 得到相同坐标。
Stop 停止播放，同时清空后端队列。
Step 暂停时逐段执行。
Import 打开文件选择器导入 .gcode / .gco / .g 文件（也可以直接拖到窗口）。
Clear 清空已绘制的 3D 轨迹（编辑器内容保留）。
Drag & Drop 将 .gcode 文件拖到窗口任意位置即可导入。
三、面板参数
播放倍速 0.1x – 2000x。作用于浏览器本地播放与后端虚拟时钟，Hermes 的 TCP 指令跟随同一速度。
颜色模式 Z 渐变 / 彩虹 / 单色 / 多色。多色模式下响应 M600 与 T0–T3。停止或换文件后保留上次选择。
风扇 (Fan) P0 模型风扇、P1 热端风扇（≥50°C 强制 100%，auto）、P2 控制器风扇。滑块发 M106 P<n> S<0-255>。
Z 轴高度 拖动裁剪平面查看模型内部。下方淡蓝条表示模型总高占床高的比例。
任务预估 耗时、线材长度（m）、重量（g，密度 1.24g/cm³）、层数。由 G-code 预分析得出。
Jog X± / Y± / Z± 6 个方向，Home 执行完整 G28 序列。
终端 直接输入任意 Marlin G-code。M105/M114/M115/M119/M503 会返回查询结果。
质量 层高、外壳厚度、回抽开关（从 G-code 头注释自动填充）。
填充 底部/顶部厚度、填充密度（%）。
速度 & 温度 打印速度、热端温度、热床温度。运行前未显式指定时，作为预热目标。
支撑 支撑类型与平台附着类型，仅用于面板回填，不参与仿真。
线材 线材直径与流量倍率（对应 M221）。
机器设置 喷嘴直径、床 X/Y/Z。改变后会即时重建 3D 工作区与裁剪平面。
四、快捷键
Space 运行 / 暂停（焦点不在输入框时）。
Esc 停止播放。
Home 执行 G28。
Ctrl+Enter 在终端输入框发送当前指令。
五、状态栏与固件协议
X/Y/Z/E 当前逻辑坐标与累计挤出量。
Q / Ring 执行队列长度 / 环形缓冲区占用。
T / B 热端 / 热床 当前温度 / 目标温度。
F 当前进给速度（mm/min）。
Spd / Flow 速度倍率（M220）与流量倍率（M221）。
Fan P0 / P1 / P2 三路风扇 PWM 百分比与估算转速。
Idle / Paused / Printing 播放状态。固件协议文本（ok T:、ok X: 等）保持英文以对齐真机。

关于本软件

版本：v3.3.0 (Pro)

简介：基于单文件 SPA 纯前端架构的高精度 3D 打印机仿真器。深度模拟 Marlin 固件行为、PID 热力学及运动学规划。

技术栈：Three.js (3D), Vanilla JS (Logic), SVG Filters (Gooey UI)

v3.3.0 更新日志

  • 风扇按标准 Marlin M106/M107 支持 P0/P1/P2 三路；热端风扇增加 EXTRUDER_AUTO_FAN_TEMPERATURE 50°C 门控
  • 喷嘴右侧新增 3D 小风扇模型，扇叶随 P0 PWM 旋转
  • G28 与真机一致：Z 抬升 → X/Y/Z 快速归位 + bounce + 二次慢速
  • 颜色模式停止或换文件后保留用户上次的手动选择
  • 新增 SSE 连接指示灯、G-code 文件拖放、键盘快捷键
  • 修复 G-code 编辑器横向溢出无滚动条的问题

v3.2.6 更新日志

  • 修复计算层数时将“纯 E 轴测试挤出”误算为打印层数的问题
  • 优化拉丝防断裂效果，强制延长渐隐距离
